三、知识背景

3.1 文本分类的基本流程

文本分类通常分为以下步骤：

原始文本
  -> 分词与规范化
  -> 文本表示（特征提取）
  -> 训练分类器
  -> 在验证集上检查或选择模型
  -> 在测试集上计算 Accuracy 和 Macro-F1

核心原则是：

  • 词表、词频等统计量只能从 Training Set 获得；
  • Validation Set 用于监控或选择模型；
  • Test Set 只做最终评价，不能反复调参；
  • 所有方法使用同一份数据划分，保证可比性。

3.2 分词与词表

BoW 和 Word2Vec 使用统一分词规则：

  1. 文本转为小写；
  2. 使用 NLTK TreebankWordTokenizer 分词；
  3. 删除不含字母或数字的纯标点 token；
  4. 保留数字及混合 token。

词表是从训练集统计得到的所有不同词组成的集合：

V={w1,w2,…,w|V|} V=\{w_1,w_2,\dots,w_{|V|}\}

其中 |V||V| 表示词表大小。

3.3 Bag-of-Words 原理

Bag-of-Words 把一篇文档表示为一个 |V||V| 维向量，并忽略词序。

Binary Bag-of-Words 只记录词是否出现：

xi={1,wi 在文档中出现0,wi 未出现 x_i= \begin{cases} 1,& w_i\text{ 在文档中出现}\\ 0,& w_i\text{ 未出现} \end{cases}

Word Frequency 记录词的出现次数：

xi=词 wi 在当前文档中的出现次数 x_i=\text{词 }w_i\text{ 在当前文档中的出现次数}

BoW 的优点是简单、可解释、训练快；缺点是维度高且稀疏，无法表示词序和语义相似关系。

3.4 Logistic Regression 原理

Logistic Regression 用于多分类时，对类别 cc 计算线性得分：

zc=wc⊤x+bc z_c=w_c^\top x+b_c

再通过 Softmax 把得分转为概率：

P(y=c∣x)=ezc∑k=1Kezk P(y=c\mid x)=\frac{e^{z_c}}{\sum_{k=1}^{K}e^{z_k}}

训练时最小化交叉熵损失：

L=−1N∑i=1Nlog⁡P(yi∣xi) L=-\frac{1}{N}\sum_{i=1}^{N}\log P(y_i\mid x_i)

本实验中，所有 Logistic Regression 使用相同配置：C=1.0、solver="lbfgs"、max_iter=2000、random_state=42。

3.5 Word2Vec 原理

Word2Vec 学习每个词的稠密低维向量，其基本假设是：出现在相似上下文中的词往往具有相似含义。

CBOW 根据上下文词预测中心词，目标是最大化：

∑tlog⁡P(wt∣wt−c,…,wt−1,wt+1,…,wt+c) \sum_{t}\log P(w_t\mid w_{t-c},\dots,w_{t-1},w_{t+1},\dots,w_{t+c})

Skip-gram 根据中心词预测上下文词，目标是最大化：

∑t∑−c≤j≤c,j≠0log⁡P(wt+j∣wt) \sum_{t}\sum_{-c\le j\le c,\,j\ne 0}\log P(w_{t+j}\mid w_t)

本实验使用 Skip-gram 结构。训练得到的词向量可用于表示文档。

3.6 GloVe 原理

GloVe 利用全局词共现信息学习词向量。它先统计词 wiw_i 和 wjw_j 共同出现的次数 XijX_{ij}，然后让词向量内积近似表示共现的对数：

wi⊤w̃j+bi+b̃j≈log⁡Xij w_i^\top \tilde w_j+b_i+\tilde b_j \approx \log X_{ij}

本实验直接使用公开的 glove.6B.100d 预训练词向量。

3.7 文档向量的平均池化

对于一篇包含 nn 个有效词的文档，文档向量通过对所有有效词向量求平均得到：

e(d)=1n∑i=1ne(wi) e(d)=\frac{1}{n}\sum_{i=1}^{n}e(w_i)

如果某个词不在词向量表中，则视为 OOV 词并忽略。若一篇文档没有任何有效词，则使用零向量。

3.8 BERT 原理

BERT 基于 Transformer 的自注意力机制，能够根据上下文动态表示每个词。自注意力中，词与词之间通过注意力权重交互：

Attention(Q,K,V)=softmax(QK⊤dk)V \text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V

BERT 使用 [CLS] token 的表示接入分类层。本实验使用 google-bert/bert-base-uncased，在分类任务上端到端微调：

[CLS] 表示 -> Dropout -> Linear -> Softmax -> 3 类概率

3.9 评价指标

Accuracy 为预测正确样本占全部测试样本的比例：

ACC=预测正确的样本数测试样本总数 ACC=\frac{\text{预测正确的样本数}}{\text{测试样本总数}}

对每个类别分别计算 Precision、Recall 和 F1：

Precision=TPTP+FP,Recall=TPTP+FN,F1=2PRP+R Precision=\frac{TP}{TP+FP},\quad Recall=\frac{TP}{TP+FN},\quad F1=\frac{2PR}{P+R}

Macro-F1 对所有类别的 F1 取平均：

Macro-F1=1K∑c=1KF1c Macro\text{-}F1=\frac{1}{K}\sum_{c=1}^{K}F1_c

本实验数据中 sports 约占 75%，因此 Accuracy 容易偏高，必须同时使用 Macro-F1 观察少数类表现。

4.2 统一预处理

def tokenize_text(text: str) -> list[str]:
    tokens = _TOKENIZER.tokenize(str(text).lower())
    return [token for token in tokens if any(ch.isalnum() for ch in token)]

BERT 使用其自身的 WordPiece Tokenizer，不能复用上述分词结果，因为 Transformer 模型必须使用与预训练模型匹配的分词器。

六、实验总结

本次实验完成了三种文本表示方法在 NYT 新闻三分类任务上的比较。

在 Bag-of-Words 部分，Binary BoW 和 Word Frequency 都取得了很高效果，其中 Word Frequency 因保留词频信息而优于 Binary BoW，说明在新闻分类中关键词强度是有用的判别信号。

在 Word2Vec 部分，NYT 领域内训练的 Word2Vec 优于 GloVe 和 AG News Word2Vec。领域一致性越高、OOV 越少，平均文档向量越稳定。同时发现，平均词向量在这类长文本、类别词特征明显的任务中不如高维稀疏词袋。

在 BERT 部分，上下文表示和端到端微调使少数类表现明显优于平均词向量方法。但由于题目固定 max_length=64，模型只能看到文档开头，最终 Macro-F1 略低于 Word Frequency。

整体而言，本实验最重要的收获是：文本表示方法没有绝对的优劣，需要结合任务特点、文本长度和输入限制来分析。当类别关键词特征明显时，简单词袋可能更强；当需要上下文语义时，BERT 更有优势，但其效果也受到截断长度的约束。
